# IBM Plex Sans

Arquivos estáticos Regular (400), Medium (500) e Bold (700), obtidos em 28/10/2026 do [repositório oficial IBM/plex](https://github.com/IBM/plex/tree/master/packages/plex-sans/fonts/complete/ttf). Licença original em [OFL.txt](OFL.txt), copiada de `IBM/plex/LICENSE.txt`.

Os TTF são `EmbeddedResource` e registrados uma vez pelo `GeradorDocumentoOrcamento`. O PDF incorpora apenas os glifos utilizados. O fallback Lato acompanha o QuestPDF, sem exigir fontes instaladas no sistema.
